# Sovereign: Age of Nations

Build your nation. Shape your world. Define history.

Real-time grand strategy and geopolitical simulation, built with free tools only.

## Structure

- `frontend`: React + Vite + TypeScript
- `backend`: Cloudflare Worker (Hono)
- `shared`: shared types, schemas and (later) the simulation engine

## Run locally

    npm install
    npm run dev:backend   # terminal 1
    npm run dev:frontend  # terminal 2
